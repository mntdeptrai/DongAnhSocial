================================================================================
[5] CẤU HÌNH QUEUE WORKER — SUPERVISOR (aaPanel)
================================================================================

# Trong aaPanel → Supervisor → Add Program
# Hoặc tạo thủ công file config:

sudo nano /etc/supervisor/conf.d/food-map-queue.conf

# Nội dung file:
# -----------------------------------------------
[program:food-map-queue]
process_name=%(program_name)s_%(process_num)02d
command=php /www/wwwroot/YOUR_DOMAIN/artisan queue:work database --sleep=3 --tries=3 --max-time=3600
directory=/www/wwwroot/YOUR_DOMAIN
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=www
numprocs=2
redirect_stderr=true
stdout_logfile=/www/wwwroot/YOUR_DOMAIN/storage/logs/queue-worker.log
stopwaitsecs=3600
# -----------------------------------------------

# Reload Supervisor:
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start food-map-queue:*

# Kiểm tra trạng thái:
sudo supervisorctl status

================================================================================
[7] CẤU HÌNH NGINX REVERSE PROXY CHO WEBSOCKET (HTTPS)
================================================================================

# Thêm block sau vào trong server block của Nginx site config
# (aaPanel → Website → Config → Nginx Config)
# Dán vào TRƯỚC dòng "location / { ... }")

# -----------------------------------------------
    # Reverse Proxy cho Reverb WebSocket
    location /app {
        proxy_pass             http://127.0.0.1:8080;
        proxy_http_version     1.1;
        proxy_set_header       Upgrade $http_upgrade;
        proxy_set_header       Connection "Upgrade";
        proxy_set_header       Host $host;
        proxy_set_header       X-Real-IP $remote_addr;
        proxy_set_header       X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header       X-Forwarded-Proto $scheme;
        proxy_read_timeout     60s;
        proxy_connect_timeout  60s;
        proxy_send_timeout     60s;
    }
# -----------------------------------------------

# Sau khi chỉnh Nginx, reload:
sudo nginx -t
sudo nginx -s reload

# Nếu dùng HTTPS, cập nhật .env:
# REVERB_SCHEME=https
# REVERB_PORT=443
# Và trong file .env của Vite (nếu dùng Vite build):
# VITE_REVERB_SCHEME=https
# VITE_REVERB_PORT=443

# Build cache production (tăng tốc đáng kể)

# Tối ưu Composer autoloader
composer dump-autoload --optimize --no-dev

# Phân quyền thư mục storage và bootstrap/cache
chmod -R 775 storage bootstrap/cache
chown -R www:www storage bootstrap/cache

# Tạo symlink storage (nếu dùng local disk, bỏ qua nếu dùng R2)
php artisan storage:link


================================================================================
[9] MỞ FIREWALL PORT (aaPanel)
================================================================================

# aaPanel → Security → Firewall → Add Rule:
# Port: 8080 | Protocol: TCP | Action: Accept | Remark: Reverb WebSocket

# Hoặc dùng lệnh:
sudo ufw allow 8080/tcp
sudo ufw reload

# Kiểm tra firewall:
sudo ufw status

# LƯU Ý: Nếu dùng Nginx reverse proxy (HTTPS setup ở mục [7]),
# KHÔNG cần mở port 8080 ra ngoài — chỉ cần mở 80 và 443.

================================================================================
LƯU Ý BẢO MẬT QUAN TRỌNG
================================================================================

1. Đảm bảo APP_DEBUG=false trong production
2. Đảm bảo APP_ENV=production
3. File .env phải thuộc sở hữu user www và có quyền 640:
   chown www:www .env && chmod 640 .env
4. Không bao giờ commit file .env lên Git
5. Cấu hình SSL/HTTPS cho toàn bộ site (Let's Encrypt trên aaPanel)
6. Bật Cloudflare nếu có để bảo vệ DDoS và cache tĩnh
7. Backup database định kỳ — cấu hình trong aaPanel → Databases → Backup
